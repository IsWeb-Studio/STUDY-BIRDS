# Recognition artwork

These bundled images are fallbacks only for matching recognition records returned by the server. They never create additional recognition records. Admin-uploaded images take precedence.

- british-council.png: rendered from the existing client/public/british.svg artwork; cropped to the logo bounds.
- techne-summit.png: Techne wordmark downloaded from https://www.technesummit.com/storage/events/1/settings/2-main_logo.png (official 2025 site), displayed in navy via Flutter's image tint.
- iso-9001.png and iso-10002.png: locally drawn blue circular standard labels matching the supplied layout; these are not a certification body's proprietary seal.
