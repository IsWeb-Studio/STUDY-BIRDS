## التحقق الذي أضيف على الخادم

- يمنع مسار تعديل الملف الشخصي تغيير البريد مباشرة؛ يلزم تدفق توثيق الحساب.
- يرفض قيم الملف الشخصي ذات الأنواع غير الصحيحة، والهاتف غير الصالح عند تغييره، والمعدل السالب أو غير الرقمي، وتاريخ الميلاد المستحيل أو المستقبلي، والمرحلة غير المدعومة.
- يرفض رموز الجنسية والإقامة غير الموجودة في سجل `Country` وعدم تطابق بلد الإقامة الظاهر مع رمزها.
- يضيف `nationalityCountryCode` و`currentResidenceCountryCode` و`targetCountryCodes` كحقول إضافية متوافقة، مع إبقاء الأسماء القديمة التي لا تقابل سجلًا معروفًا.
- يتحقق من رموز جهات الدراسة مقابل سجل الدول، ويتأكد أيضًا أن لكل رمز جامعة مدرجة. لا يعتمد على قيمة من القائمة يرسلها العميل.
- يحافظ على الوجهات القديمة المحفوظة إذا لم تعد لها جامعة مدرجة، ويسمح بإزالتها؛ لكنه يرفض إضافتها كوجهة جديدة. هذا يحمي ملفات الطلاب القديمة من الفشل عند حفظ حقل آخر.
- يتحقق من ملف المتقدم في طلب التقديم، مع إبقاء `applicantProfile` اختياريًا للتوافق مع العملاء الأقدم.
- أضاف `GET /universities/available-countries` لعرض الدول التي تضم جامعة واحدة على الأقل. لا يغيّر endpoint الجامعات الحالي.

رفع الملفات الحالي على الخادم يقيّد ملف المستند إلى 5 MiB، وستة ملفات و50 حقل نموذج لكل طلب، ويفحص MIME وبصمة محتوى الملفات. لذلك أضفت حد الواجهة إلى المكوّن المشترك للمستندات؛ ما زالت حقول رفع الصور الإدارية المباشرة تعتمد على قواعد endpoints الخاصة بها وتحتاج مراجعة مستقلة لكل نوع رفع.

## قرارات وحدود متبقية

1. **مقياس المعدل:** قواعد البيانات الحالية لا تحفظ مقياس المعدل بجانب قيمة GPA؛ لا توجد قاعدة موثقة لتحديد 4 أو 5 أو 100. لذلك تُقبل قيمة عددية غير سالبة بلا حد أعلى مخمّن. يلزم قرار منتج يضيف نوع المقياس أو يرتبط بالمدرسة/البرنامج قبل فرض حد أعلى.
2. **المدينة والمنطقة:** لا يوجد كتالوج موحد موثق للمدن والمناطق لكل بلد. حقول المنطقة النصية تبقى كما هي، مع قوائم محلية للمناطق حيث تتوفر. لا يُحذف اختيار قديم بصمت.
3. **الجامعة الخارجية:** تدفق طلب البرنامج يستخدم معرف برنامج حقيقي. لم أغيّر الحقول الإدارية أو الشريكة التي قد تسمح باسم جامعة خارج الكتالوج؛ يجب تقرير وجود مسار منفصل «جامعة أخرى» قبل استبدالها باختيار إلزامي.
4. **المواعيد الديناميكية:** لا يمكن استنتاج المواعيد المتاحة من شكل الحقل وحده؛ القاعدة المرجعية هي API الحجز. لم أختلق مواعيد أو أغير قواعد التوافر.
5. **أنواع الملفات:** بعض واجهات الويب الإدارية تستخدم عناصر ملف مباشرة بدل `DocumentPicker`. ينبغي ربطها بمكوّن رفع مخصص لكل endpoint حتى تعرض رفض النوع/الحجم قبل الإرسال.
6. **تغطية كل شاشة:** الجرد يحدد كل مواقع الإدخال والتحقق ساكنًا، لكنه لا يثبت أن كل حقل إداري أو حقل يتولد من استجابة API صار له اختبار سلوكي فردي. يلزم استمرار المراجعة على مستوى كل نموذج مع قواعده التجارية، خصوصًا النماذج الإدارية متعددة الأنواع.

لم أغيّر Git أو البيانات المنشورة، ولم أعمل reset أو stash أو commit أو push أو deploy. احتفظت بالتعديلات السابقة كما كانت.
