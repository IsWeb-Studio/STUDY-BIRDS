# Phase 7 — الموافقات والحواجز المتبقية

## IMPLEMENTED / VERIFIED دون موارد خارجية

اشتغل MongoDB المحلي الموجود مسبقًا، بقاعدة QA محددة ومصادقة محدودة، وbackend loopback وHTTPS وبريد محلي وتخزين مستندات محلي وحسابات خيالية. لا حاجة الآن لموافقة تثبيت MongoDB أو Docker؛ لم يُثبت أو يُنزّل شيء. لا تغيير على الإنتاج أو بياناته.

## مطلوب قبل Android

1. يختار المالك جهازًا/محاكيًا مخصصًا لا يحمل التطبيق أو بيانات إنتاج، ويوافق على USB debugging وADB reverse المحدد. لم تُتخذ هذه الخطوات تلقائيًا.
2. يُثبت منع خروج OS/native/browser إلى خدمات الإنتاج. manifest ما زال يحوي autoVerify لنطاق الإنتاج وpackage الإنتاج. يلزم اختيار جهاز USB معزول فعليًا أو تصميم QA variant/applicationId/manifest منفصل. التوصية طويلة الأجل هي variant مستقلة، لكن لم يُفترض اسم package أو يُنفّذ تغيير Gradle/manifest غير متحقق.
3. يُراجع فتح المستندات والصور/native media وثقة الشهادة على Android. يدعم Dart API شهادة QA صريحة، لكن المتصفح/الوسائط الأصلية لا تُعتمد بافتراض استعمالها الإعداد نفسه. أي تثبيت شهادة أو تغيير إعداد جهاز يتم بموافقة المالك وعلى جهاز QA فقط.
4. توفير هامش مساحة مناسب، مع خطة artifact/output منفصل تحمي APK القديم قبل البناء. لا حذف إضافي أو flutter clean أو تعديل build config العام ضمن هذا العمل.

عند اكتمال هذه الشروط فقط، يمكن مراجعة تفعيل QA_RESOURCES_VERIFIED لإعداد جهاز حقيقي وبناء QA. لا تُنسخ راية true من ملفات اختبارات الكمبيوتر.

## موافقة مستقلة إذا طُلبت

- تثبيت/تحديث Docker أو MongoDB أو WSL أو binary أو dependency مفقود، أو تنزيل صورة حاوية. الحالي موجود ويعمل؛ السكربت يرفض استبدال binary المعروف تلقائيًا.
- LAN binding أو firewall أو router forwarding أو tunnel. الخيار الحالي loopback/USB، ولا حاجة لتوسيع التعرض بهدوء.
- OAuth/Google/Apple أو OneSignal/FCM أو SMTP/Brevo أو Cloudinary أو telemetry أو payments بمزوّد مستقل. هذه الخدمات الحية غير مختبرة ولا تُنشأ projects أو keys تلقائيًا.
- تشغيل utilities الإدارية لترحيل مستندات قديمة أو backfill أو backup/CRM credentials؛ لم تُنفّذ وليست جزءًا من QA launcher. أداة seed الماسحة القديمة محجوبة؛ لا reset/drop تلقائي لقاعدة QA أو غيرها.
- أي حذف للبيانات/المجلدات/الحاويات/الأحجام/checkpoints، أو تغيير توقيع أو credentials إنتاج، أو commit/push/deploy.

لا توجد خطوة إنتاج مطلوبة لإنجاح الاختبارات المحلية. لا تمنح هذه الوثيقة إذنًا لأي إجراء مما سبق.
